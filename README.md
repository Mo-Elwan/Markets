# منصة أسواق النفع العام الرقمية الوطنية
### National Public Benefit Markets Digital Platform

نظام رقمي تفاعلي يجسد رؤية ربط أسواق النفع العام (التاجر، المزارع، مستأجر المزرعة) بالمستهلك النهائي مباشرة مع حوكمة إدارة السوق وتقديم خدمات الوسطاء اللوجستيين للتغليف والتوصيل.

## 🎨 الهوية البصرية المعتمدة (منصة نما - وزارة البيئة والمياه والزراعة)

- **شعار الوزارة:** تم تضمين الشعار الرسمي لوزارة البيئة والمياه والزراعة (MEWA).
- **الخط المعتمد:** خط **Tajawal (تجوال)** العربي الحكومي الرسمي.
- **لوحة الألوان (Design Tokens):**
  - **الأخضر الملكي الأساسي:** `#006837`
  - **الذهبي الملكي (نما):** `#c59b27`
  - **الخلفيات والبطاقات:** بطاقات رقمية ناصعة بظلال ناعمة وإشارات حالة معتمدة.
- **التكامل الحكومي:** ترويسة وتذييل متطابقان مع معايير المنصات الحكومية التابعة لمنظومة نما والوزارة.

1. **إدارة السوق والرقابة (Super Admin Portal):**
   - استعراض طلبات إدراج المنتجات الواردة من التجار والمزارعين.
   - **الاعتماد الكلي أو الجزئي**: قبول أصناف معينة ورفض أخرى.
   - **تعديل الكميات المعتمدة**: إمكانية تعديل الكمية المسموحة (مثلاً طلب 1000 كجم طماطم -> اعتماد 600 كجم فقط).
   - **تسجيل أسباب الرفض**: (مخالفة اشتراطات السوق، صور غير مطابقة، منتج غير مسموح، إلخ).
   - مؤشرات الأداء الحية (المبيعات، إيرادات المنصة، المنتجات المعتمدة).

2. **بوابة التاجر / المزارع (Merchant & Farmer Portal):**
   - تسجيل بيانات المزارع والسجل التجاري أو وثيقة العمل الحر.
   - إدخال حزمة منتجات (الاسم، التصنيف، الكمية، الوحدة، السعر، الصورة).
   - **اختيار آلية البيع والتنفيذ (Fulfillment Selection)** فور اعتماد الصنف:
     - **الخيار الأول (البيع المباشر)**: التاجر يتولى التجهيز والتوصيل للمستهلك مباشرة.
     - **الخيار الثاني (البيع عبر وسيط)**: إسناد المنتج لمركز خدمة أو شركة وسيطة معتمدة (تتولى الاستلام، التغليف، والشحن المبرد).

3. **متجر المستهلك (Consumer Storefront):**
   - تصفح المنتجات الزراعية الطازجة المعتمدة فقط من الرقابة.
   - وضوح آلية التوصيل لكل منتج (شحن مباشر من المزرعة أو عبر وسيط تغليف معتمد).
   - سلة تسوق وإتمام الطلب مع تحديث فوري للمخزون ومنع البيع الزائد.

4. **بوابة الوسيط اللوجستي (Broker Logistics Hub):**
   - استعراض الشحنات المسندة لشركات التوصيل والتغليف.
   - تحديث حالات الشحنة (استلام، قيد التجهيز والتغليف، جاري التوصيل، تم التسليم).
   - كشف حساب أتعاب الوسيط المستحقة تلقائياً من كل طلب.

## 🚀 طريقة التشغيل السريعة

### الخيار 1: عبر ملف التشغيل السريع (Windows)
- اضغط نقراً مزدوجاً على الملف: `start.bat`

### الخيار 2: عبر سطر الأوامر (Terminal / PowerShell)
```powershell
python -m uvicorn main:app --host 127.0.0.1 --port 8000 --reload
```

ثم افتح المتصفح على الرابط:
👉 **[http://127.0.0.1:8000](http://127.0.0.1:8000)**
